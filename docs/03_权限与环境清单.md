## B. 域名与服务器

### B1 · 域名 DNS 管理权 🔴

- **是什么**：`shouyou.me` 的注册商/解析服务后台（阿里云万网 / 腾讯云 / Cloudflare 等）
- **为什么**：要给游戏挂一个子域名（比如 `play.shouyou.me`），还要**设置 COOP/COEP 响应头**（见下面 B3 的红字警告）
- **怎么给我**：
  - 如果 DNS 在 **Cloudflare**：给我一个能编辑 DNS 和 `_headers` 的账号，或你自己加记录
  - 如果在**阿里云/腾讯云**：给我子账号（只给 DNS 权限即可），或你按我给的记录手动加
  - **最简单**：把域名的 NS 转到 Cloudflare（免费），后面全都能自动化
- **当前状态**：❌ 未提供

### B2 · 托管（服务器或静态托管） 🔴

- **推荐方案**：**Cloudflare Pages**（免费、全球 CDN、能自定义响应头、能自动从 GitHub 仓库部署）
- **备选**：你自己的服务器（需要 SSH 权限 + 我能装 nginx）
- **为什么**：Godot 导出的网页版是 30MB+ 的静态文件，必须有个地方放
- **当前状态**：❌ 未提供

### B3 · ⚠️ 服务器必须能设置响应头（这是 Godot 网页版的生死线） 🔴

Godot 4 的 Web 导出默认使用**多线程 + SharedArrayBuffer**，浏览器只在下面两个响应头存在时才允许：

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

**不设这两个头，网页版会白屏或卡在加载页。**

- Cloudflare Pages：在仓库里放一个 `_headers` 文件即可（我会写好）
- 自己的 nginx：需要 `add_header` 配置
- **备用方案**：Godot 导出时勾选"无线程"，体积小一点、兼容性最好，但性能略低
