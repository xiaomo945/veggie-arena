- **怎么给我**（两种都行，**推荐第一种**）：

  **方式一 · classic token（推荐）**
  1. https://github.com/settings/tokens → **Generate new token → 选 classic**
  2. 勾选 **`repo`**（整块，包含下面所有子项）——**只勾子项不行，必须勾整块，否则无法创建仓库**
  3. 生成后把 `ghp_xxxx` 发我

  **方式二 · fine-grained token**
  1. Repository access 选 **All repositories**
  2. Permissions → Repository permissions：
     - **Contents: Read and write**（推送代码）
     - **Administration: Read and write**（创建仓库）
     - Metadata: Read-only（自动）
  3. 生成后把 `github_pat_xxxx` 发我

- **⚠️ 三个已踩过的坑（2026-09-30 实测）**：
  1. **账号串了**：连着两个 token 都不是 `xiaomo945`，分别属于 `shield007008`（2017 年建）和一个 2022 年建的账号。**生成 token 前务必看右上角头像**
  2. **权限不足**：fine-grained token 默认**不能创建仓库**，GitHub 返回 `Resource not accessible by personal access token`
  3. **没有 scope 的 token 推不动**：响应头里没有 `x-oauth-scopes` 就说明没有写权限

- **当前状态**：🔴 **四次尝试均失败**（2026-09-30）

  | # | 来源 | 归属账号 | 结果 |
  |---|---|---|---|

  | 2 | 手工 `ghp_` | `XxXxXx…X0`（2022 建） | ❌ 无写权限（响应头无 `x-oauth-scopes`）|
  | 3 | **GitHub 连接器（OAuth）** | `XxXxXx…X0`（2022 建） | ❌ 连上了，但**不能创建仓库**（403）|
  | 4 | — | — | ⏳ 等你建空仓库后试 push |

## B. 域名与服务器

### B1 · 域名 DNS 管理权 🔴

- **是什么**：`shouyou.me` 的解析后台
- **已知**：✅ **域名在 Vercel**（2026-09-30 确认）

- **当前状态**：🟡 已知在 Vercel，具体域名待确认

### B2 · 托管 🔴

- **方案**：✅ **Vercel**（用户已有账号，域名也在那）
- **优点**：自动从 GitHub 仓库部署、全球 CDN、能用 `vercel.json` 自定义响应头、免费额度够用
- **⚠️ 体积提醒**：Godot Web 导出的 `.wasm` 约 **30–35MB**。Vercel 免费版对单个静态文件没有硬性上限，但部署包总量要留意。
  优化手段：
  1. 用 `--export-release` 导出（去掉调试符号，体积小很多）
  2. 导出"无线程"版本（可去掉 COOP/COEP 依赖，兼容性最好）
  3. Vercel 自动开 Brotli 压缩，传输体积会小很多
- **当前状态**：🟡 需确认 Vercel 是否已连接 GitHub 仓库

### B3 · ⚠️ COOP/COEP 响应头（Godot 网页版的生死线）🔴

Godot 4 的 Web 导出默认使用**多线程 + SharedArrayBuffer**，浏览器只在下面两个响应头存在时才允许：

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

**不设这两个头，网页版会白屏或卡在加载页。**

- ✅ **已解决**：`web/vercel.json` 已写好（Vercel 用 `vercel.json`，不是 Cloudflare 的 `_headers`）
- 若改用 Cloudflare Pages：需要 `_headers` 文件
- 若用自有 nginx：需要 `add_header`
- **兜底**：Godot 导出时勾选"无线程"，不需要这两个头
