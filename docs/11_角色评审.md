# 11 · 角色评审：用户画像打分与命名

> 目的：每个角色做完之后，站到**目标玩家的视角**上打分 —— 名字讨不讨喜、
> 玩法有没有辨识度、值不值得为它开一局。名字是出海市场的第一印象，
> 一个记不住的名字等于这个角色白做。

**状态：第 4 节改名方案已落地到 `data/characters.json`（10 个 EN + 3 个 ZH），
守门测试全绿。** 下面第 3 节的"改名前"评分保留作为对照基线，
下次新增角色时按同一张表打分，低于 18 分就打回重起名字。

**平均分 15.8 / 25**，最高 20（刺猬），最低 11（田园）。

### 诊断：三个硬伤

1. **"X Turnip" 模板化** —— 十个名字同一句式，选角页扫过去像在看蔬菜清单，
   记不住谁是谁。Brotato 的做法是**一个词**（Loud / Ghost / Cyborg / Well-Rounded）。
2. **缺厨房梗** —— Mage / Archer / Commando 是通用奇幻词，放在任何游戏里都成立，
   也就等于在我们的厨房竞技场里**没有身份**。
3. **中英文名不对仗** —— 灵能 / 武术家 / 特种兵 与 Mage / Martial / Commando
   只是直译，两边都没抓住"这角色怎么玩"。

## 6. 画像评审 2.0：6 画像 × 7 维（当前生效的版本）

第 1~5 节是早期方案（4 画像、只评名字）。**现在生效的是这一节**，
数据与判定在 `data/char_review.json` + `scripts/char_review.py`，
并已并入 `scripts/check.sh` 第 2.7 步（硬失败）。

用户原话：
> 用户画像就是轻度用户、中度用户、重度用户啊，还有啊，男生女生的喜好这样来评分儿…
> 他使用的武器，他的名字，他的玩法，爽感，它的特效美术，每一个环节都要模仿用户画像
> 给这个角色打分儿…都满意了，或者是打到一个比较高的分儿，这个角色才能做。

### 6.1 画像与维度

- **画像 = 3 档投入度 × 2 性别偏好 = 6 个**（轻度/中度/重度 × 女/男）。
  女性画像重"美术 + 名字 + 有性格"，男性画像重"强力 + 效率 + 上限"。
- **维度 7 个**：用户点名的 5 项（名字 / 武器 / 玩法 / 爽感 / 特效美术）+ 构筑深度 + 上手门槛。
- **两个闸门**：① 每个画像加权分 ≥ 3.40（**不取平均** —— 取平均会让
  "重度爱死、轻度看不懂"的角色蒙混过关）；② 任何一项 ≤ 2 即硬伤，直接不过。

### 6.2 第一轮评审结果（2026-10）：13 个角色里 3 个打回

| 角色 | 问题 | 改造 | 结果 |
|---|---|---|---|
| 田园萝卜 | `play`/`depth` = 2 硬伤：它是"什么都不会错"的兜底角，没有自己的玩法 | **新增第三条羁绊线 `variety`（杂食）**：按武器【类种数】分档（最多 5 类），与 bond 的"堆同一类"方向相反 —— 全游戏唯一不鼓励堆同一把的角色。改名 **杂食萝卜 / Omnivore**，读一遍名字就知道该怎么买 | play/depth 2→4，六画像 3.90~4.04 ✅ |
| 焦辣萝卜 | `onboard` = 2 硬伤：DoT 只挂在技能上，选它开枪三秒看不到一点火，只看到普攻比别人低 | **新增角色自带命中 DoT（`on_hit_dot`）**：每一发命中都直接点燃灼烧 + 上毒（`apply_fx` 取 max 不叠层），吃 `elem_pct` 放大，第一次命中就看得见 | onboard 2→4，六画像 4.62~4.84 ✅ |
| 爆炒萝卜 | `onboard` = 2 硬伤：输出全在颠勺那一下，不读 tip 的人看不懂 | **开局白送 1 次颠勺充能（`start_wok_charges`）**：进局按一下就知道输出在哪，不用先读懂火候条 | onboard 2→3（仍是全场最极端的玩法，诚实的分），六画像 4.42~4.82 ✅ |

### 6.3 改分的规矩

改分必须对应一次真实的代码/数值改动，理由写进 `char_review.json` 的 `notes`，
时间线写进 `_history`。**禁止只改数字不改游戏** —— 那样这张表就只是自我安慰。

### 6.4 顺带修掉的两个真 bug（截图目检抓出来的）

1. **换角色后技能按钮不换招**：`SkillButton` 只在 `_ready` 取一次技能 id，
   角色是进战斗前才定的，按钮会一直显示上一个角色的招。现在监听
   `Events.character_changed` 重新解析（显示名 / 配色 / 冷却一起换）。
2. **三条羁绊进度在 540 竖屏放不下**：`HudSynergy` 现在先量总宽，超宽自动切
   精简模式（去掉"还差 N 件"，保留"进度条 + 3/5"）。砍副标题而不是砍整条 ——
   少一条线玩家就以为自己没有那条成长线。
