## 二、待做 backlog（按我建议的优先级）

### P0 — 你会立刻感受到的
1. **主角看不见了**（✅ 已修）`ui/Screens/Main.gd` + `entities/Player/PlayerVisual.gd`
   - 根因：`game` 节点（110 敌人 + 90 子弹的池）在 player **之后** add_child，默认按树序
     绘制把主角整个埋进怪堆。
   - 修法：主角 `z_index = 6`（HUD/Fx 是 CanvasLayer 不受影响）；贴图放大 2.8→3.3、
     手绘体量 15/16→18/19，加"外亮内深"两道贴纸分离圈。
2. **明显卡顿**（🟨 第一批已做）`scenes/EnemyMind.gd` + `ui/Fx/FxLayer.gd` + `art/AmbientKitchen.gd`
   - 最大头：分离循环每帧给每个邻居 `new` 一个 Dictionary（满怪上万次/帧，GC 风暴）
     → 改成"字典池复用 + 存活快照 + 截断读取"（`Hit.separation` 加 `limit` 参数）。
   - 空特效也每帧逼 CanvasLayer 重绘 → 只在有特效/刚清空时重绘。
   - 画质档位之前**只是菜单高亮**，运行时没人读 → 现在"低画质"真的会关掉战场氛围粒子。
3. **音效完全没有**（🟨 加固完成，需真机确认）
   - 排查结论：资源在包里（含导入后的 `.oggvorbisstr`）、Sfx/Bgm 全接线、总线音量 0dB、
     浏览器 AudioContext running —— 沙箱软渲染只有 5FPS 无法复现"听感"。
   - 仍做了三处加固：不再运行时 `add_bus`（部分 Web/iOS 环境路由不生效 → 全程静音的
     经典表现），音量直接落播放器；标题 START 在手势内出第一声；任意首次按下兜底解锁。

### P1 — 玩法层面
4. **物品栏 6 格 + 合成规则**（⬜）`ui/Inventory.gd` / `ui/Shop/Shop.gd`
   - 装备**没满**时买相同武器 → 单独占格，不自动合。
   - 装备**满了**再买相同武器 → **自动合成**。
   - 手动合成：点其中一个 → 另一个消失并合并进来。
   - 商店可刷出「当前最高等级」和「比最高等级低一级」的武器。
   - 6 个格子要做**视觉样式**（现在没样式）。
5. **波次选择调试按钮**（✅ 已做）`ui/HUD/WaveSkip.gd` + `core/DebugMode.gd`
   - HUD 出现 `WAVE >>` 小按钮 → 面板选波次 → GO 直接清场开那一波。
   - **只在测试模式创建节点**：debug 构建 / URL 带 `?debug=1` / 命令行 `--debug-wave`。
     正式 release 不带参数时按钮节点根本不存在。
6. **玩家属性做全 + 独立属性页**（⬜）
