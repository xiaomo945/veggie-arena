# 12 · 解锁阶梯与职业深度树（近战 / 远程 / 法师三线）

> 用户原话提炼：**"基础角色免费玩，后面的角色要前置角色通关才能解锁 —— 就像武术家练到一定程度才能用厉害的兵器。"**
> 本文件负责两件事：① 把"耐玩"从感觉变成可验收的规则；② 给出三线完整的深度蓝图，
> 让"以后加内容"是照图施工，而不是想到哪加到哪。

---

## A. 业界调研结论（4 款标杆，拆成可抄的条款）

| 标杆 | 它做对的 | 我们可以抄什么 | 它的教训 |
|---|---|---|---|
| **吸血鬼幸存者** | 局外解锁**全是"新 build 可能性"**（新角色 / 新武器 / 新关卡），不是数值碾压；进化系统 = 满级武器 × 指定被动 → 变成另一把 | 解锁必须**改变玩法**，不给纯数值。角色 × 武器 × 技能本来就是我们的骨架（见 `docs/10_四元素联动.md`），解锁只是往里面填牌 | 后期粒子糊成一堵墙 → 我们要守住"可读性 > 华丽" |
| **土豆兄弟 Brotato** | 解锁分四类：**累计击杀**（自然到手）、**累计材料**（顺路）、**通关某难度**（真·目标）、**奇怪挑战**（教会玩家瞎试 build）；并且有**二级连锁**：用某角色通关 → 解锁某道具 | **主线 + 旁路双条件**：每一阶都能走"通关解锁"或"累计成就解锁"，避免某一局卡死就寸步难行 | 有些条件不说清楚会让人卡住 → 锁住的角色必须**显示解锁条件** |
| **灵魂石幸存者 Soulstone** | 深度最深（15 类技能 / 373 个技能 / 条件式解锁链条） | "条件门槛"的好例子：某效果持有 1 / 2 / 3 份才出现对应的强化 | **反面教材**：它把系统藏起来不教，一堆玩家玩到卸载都觉得"就这？" → 我们的门槛**必须写在玩家眼前**（详情独立页 D3-4 已经铺好这条路） |
| **肉鸽通用规律（2025 复盘）** | **局外成长上限 ≤ 局内 build 强度的 30%** —— 超过就变成"打工"，低于就爽不到长期成长 | 局外解锁给**可选项**不给强度；真正变强靠局内 build | — |

**落到一句话**：解锁 = 「新的可能性」，不是「更大的数字」；而且**每一步都必须看得见**。

### A-1. 爽感 / 手感的底层清单（美术最后弄，但手感现在就要做）

调研里 "Juice / Game Feel" 的共识项，我们已经做了一半（D3-1），剩下按 ROI 排：

| 技术 | 业界参数 | 我们的状态 |
|---|---|---|
| 输入缓冲 / 土狼时间 | 窗口 < 150ms，让玩家"自以为按准了" | D3-1 已做加速曲线与转向，缓冲尚未做 |
| 命中定帧 hit-stop | 40–80ms（重击更长），必须用**真实时间**计时器，不受 time_scale 影响 | 已有 `HitFeel`（有单测守门） |
| 屏幕震动 | 用**衰减 trauma + 噪声**，不是每帧随机；轻 2–5px / 重 8–15px | 已有；需复核有没有"小题大做" |
| Squash & Stretch | 受击 / 落地形变后再回弹 | 已有（`core/HitFeel.gd` 有单测守门） |
| Easing 而非线性 | UI 动画、相机回弹 | 部分 UI 仍是线性（待查） |
| 反馈分级 | 轻 / 中 / 重三档，**小事轻、大事响**（全屏都震 = 等于不震） | 待统一成一张分级表 |
| 多通道 | 视觉 + 音频 + 相机，至少两条 | 多数已有；音频分层不足 |
| 可访问性 | 减弱震屏 / 闪光的开关 | 设置菜单已有机位，待挂开关 |

## B. 三线 × 四阶：完整职业深度树

每一阶的**晋升手感**都对应用户举的例子：**武术家（徒手）→ 兵器（刀）→ 重武器（锤，群攻）**。

### B-1. 近战线 Melee（越走越重、越走越群）

| 阶 | 角色 | 兵器层级 | 玩法跃迁 | 解锁条件 | 状态 |
|---|---|---|---|---|---|
| M1 | 田园萝卜 turnip | 赤手 / 厨具（叉子 fork） | 教基础：贴脸、闪避、别贪刀 | **免费** | 已有 |
| M2 | 刀工萝卜 martial | 短兵（筷子 chopsticks / 削皮刀） | 连击驱动：攻速越高越强 | turnip 通关 或 累计近战击杀 800 | 已有（改为待解锁） |
| M3 | 铁壁萝卜 bruiser | 钝器（擀面杖 rolling_pin） | 正面硬扛 + 震地控场 | martial 通关 或 单局承伤 1500 | 已有（改为待解锁） |
| M4 | **大锤 Warhammer（新）** | 群攻重武器（大锤 / 石臼 mortar） | 扇形横扫 + 破防：一挥一圈敌人 | bruiser 通关 + 近战类武器累计持有 6 件 | 待做 |
| MA | 薯泥萝卜 mash / 爆炒萝卜 sizzle | 近战线**支线**（搅拌机、颠勺） | 换个思路也行：不是所有近战都得靠手 | 支线条件 | 已有 |

> 支线的意义：主线是"越来越重"，支线给"换个思路也能解决问题"，免得玩家觉得被逼着走一条路。

| 阶 | 角色 | 兵器层级 | 玩法跃迁 | 解锁条件 | 状态 |
|---|---|---|---|---|---|
| R1 | 神射萝卜 archer | 冷兵器（长弓 bow） | 单发高伤 + 穿透：比位置和预判 | **免费** | 已有（改为免费） |
| R2 | 老手萝卜 commando | 单兵火器（手枪 pistol） | 堆 6 把同类吃本命：暴击狙 | archer 通关 或 单局击杀 300 | 已有 |
| R3 | 磁铁萝卜 magnet | 连射弹幕（冲锋枪 smg） | 从"点杀"转向"泼水 + 满地捡" | commando 通关 或 远程类武器累计持有 6 件 | 已有 |
| R4 | **连弩 Repeater（新）** | 自动连弩 | 高频穿透：站成一条线不用瞄 | magnet 通关 + 单把冲锋枪攻速达标 | 待做 |

### B-3. 法师线 Magic（单点 → 群攻 → 群攻+控制 → 全屏）

| 阶 | 角色 | 兵器层级 | 玩法跃迁 | 解锁条件 | 状态 |
|---|---|---|---|---|---|
| A1 | 文火萝卜 mage | 基础法术（法杖 staff / 冰霜新星） | 教基础：范围伤害看站位 | **免费** | 已有（改为免费） |
| A2 | 焦辣萝卜 scorch | 持续伤害（喷火枪 blowtorch / 灼烧 DoT） | 从"一次打死"到"打完慢慢死" | mage 通关 或 累计元素伤害达标 | 已有 |
| A3 | **冰霜术士 Frostbinder（新）** | 群攻 + 控制 | 冰锥新星：伤害同时冻住，换来站桩窗口 | scorch 通关 + 元素类持有 4 件 | 待做 |
| A4 | **全屏大招 Feast / 宴席主厨（新）** | 全屏 | 冷却极长的清场（配合颠勺，走"终极大招"的节奏） | 冰霜术士通关 + 无尽模式到 15 波 | 待做 |

> 用户明确说："最终他就可以有超高的全屏类的法术" —— A4 就是这条线的终点。
> 它必须晚到（要求给得高），否则最爽的工具开局就给完，后面就没有目标了。

### B-4. 晋升的四条原则（写进规矩，防以后跑偏）

1. **每升一阶，按键没变，但玩法变了** —— 正好对应已经落地的技能 `form` 形态机制。
2. **新阶必须自带新兵器或新技能形态**，纯属性提升不算晋升（否则就是数值堆叠）。
3. **每一阶都要有一条旁路条件**（累计击杀 / 累计金币 / 无尽波数），防止"某一局怎么打都赢不了"把人彻底卡死。
4. **新内容先从数据走**（`characters.json` / `weapons.json` / `skills.json`），美术可以先空着 —— 与"美术最后弄"的排序一致。

## C. 解锁机制的落地规则

现有机制：`data/unlocks.json` 已经能给**武器**做解锁（`start_weapons` + `weapons` 各自的条件，
支持的判定类型有 `total_kills` / `best_wave` / `total_gold` / `wins`）。角色解锁复用同一套判定，只再加一类：

| 判定类型 | 含义 | 数据来源 |
|---|---|---|
| `free` | 开局就能玩（三条线各自的起点） | 无需判定 |
| `clear_with` | **用某个角色通关**（用户要的主线条件） | 存档里记录每个角色是否通关过 |
| `total_kills` / `total_gold` / `best_wave` | 旁路条件（直接复用武器那套） | `core/Save.gd` 已有 |
| `any_of` | 上面几个的组合（主线 OR 旁路，也支持 AND 组合） | 新增 |

存档侧要新增字段：`clears: { "<角色 key>": 通关次数 }`，每次胜利 +1。

**UI 三处必须同步**（少一处玩家就不知道该干嘛）：

- 选角页：锁住的角色做成**灰阶 + 锁图标**，卡片下方一行字写明解锁条件（不缩小卡片，详见 D3-4 的不变量）。
- 详情独立页：顶部标注"用田园萝卜通关解锁"；一旦条件达成，当场就能点「选他」。
- 标题页：沿用 `title_next` 的做法 —— 显示"下一个能解锁的角色：XXX（还差 1 次通关）"。

**守门单测**（写 `tests/test_char_unlock.gd`）：

- 三条线各自至少一个 `free` 角色（否则新玩家开局没得选）
- 每个 `clear_with` 的前置角色必须真实存在，且不能成环（A 要 B、B 又要 A）
- 每个非免费角色至少有一条**不依赖通关**的旁路条件
- 可达性：从 `free` 集合出发做 BFS，所有角色必须都能到达

## D. 任务拆分（按老规矩的小步闭环：改 → check → 提交 → 导出）

| # | 任务 | 验收标准 | 状态 |
|---|---|---|---|
| E1 | `unlocks.json` 加 `characters` 段：`free` / `clear_with` / 旁路三类条件 | 数据齐备，先不动战斗 | ✅ |
| E2 | `core/Unlocks.gd` + `Save.clears` 支持角色解锁判定 | 单测覆盖各类判定 | ✅ |
| E3 | 胜利时写 `clears`，解锁瞬间发 `Events.character_unlocked` | 结算后可 immediately 用新角色 | ✅ |
| E4 | 选角页锁定态（压暗 + 挂锁）+ 详情页首节「如何解锁」 | 三处点进去都能看懂进度 | ✅ |
| E5 | 标题页"下一把能解锁谁"（优先报角色，不再优先报武器） | 每局开始前都有一个具体目标 | ✅ |
| E6 | 守门单测（可达性 / 无环 / 旁路必有 / 无永不出现的武器） | check.sh 全绿 | ✅ |

**E1–E5 已落地的阶梯**（免费起点 3 个，其余"主线 OR 旁路"）：

| 线 | 免费 | 主线（用前一个角色通关） | 旁路 |
|---|---|---|---|
| 近战 | turnip 田园萝卜 | turnip→martial 刀工→bruiser 铁壁→mash 薯泥 | 800 杀 / 第 8 波 / 通关 2 次 |
| 远程 | archer 神射萝卜 | archer→commando 老手→magnet 磁铁 | 第 6 波 / 8000 金 |
| 法师 | mage 文火萝卜 | mage→scorch 焦辣 | 1500 杀 |
| 支线 | — | — | 疾风 1800 杀 / 刺猬 1200 杀 / 招财 5000 金 / 爆炒 通关 1 次 |

顺手修掉的真问题：40 把武器里有 20 把既不在初始清单也没有解锁规则 → 商店按解锁列表过滤，
它们永远不会出现（含筷子/喷火枪/锅铲等 5 个角色的本命武器）。现已全部可达，并由单测守门。
| E7 | 补第一个新角色：大锤 Warhammer（M4） | 近战线第一次真正变重 |
| E8 | 补 R4 连弩 Repeater、A3 冰霜术士 | 远程与法师各迈一阶 |

> E1–E6 是**机制**，E7 起是**内容**。先把机制跑通，再加内容 —— 反过来每加一个角色都要改一遍代码。

## E. 约束（照 C / D 阶段的老规矩）

- **架构守卫 R1** 单文件 ≤300 行：新的解锁逻辑必须放 `core/Unlocks.gd`（纯函数、可单测），
  `SaveMgr` 只做转发与发信号，UI 只负责显示。
- **局外成长不超过局内 build 强度的 30%**：这是调研里的硬指标，解锁只发"新可能性"。
- 美术最后弄：新角色先复用现有立绘占位（等真素材到位再换），先验证"机制好不好玩"。
