## 1. 模块划分与职责

| 模块 | 路径 | 职责 | 依赖 | 可测试性 |
|---|---|---|---|---|
| **数据表** | `data/*.json` | 所有平衡数值 | 无 | 人工改 |
| **Data** | `autoload/Data.gd` | 加载并缓存 JSON，提供只读访问 | data | ✅ |

| **Combat** | `core/Combat.gd` | 伤害结算：护甲、暴击、无敌帧、aoe、穿透 | 无 | ✅ 纯函数 |

| **Screens** | `ui/Screens/` | 开始页、死亡页、设置 | GameState | 手动 |

## 2. 关键接口（先定接口，再写代码）

### `core/Combat.gd`

```gdscript
# 纯函数，不引用任何 Node
static func damage_after_armor(raw: int, armor: int) -> int
static func can_be_hit(ifr: float) -> bool          # 无敌帧判定
static func apply_aoe(center: Vector2, radius: float,
                      targets: Array, dmg: int) -> Array   # 返回受影响目标
```

### `core/Spawner.gd`

```gdscript
static func spawn_rate(wave: int, cfg: Dictionary) -> float
static func pick_type(wave: int, rng: RandomNumberGenerator) -> String
static func edge_position(side: int, arena: Rect2) -> Vector2
static func stats_for(type: String, wave: int, cfg: Dictionary) -> Dictionary
```

### `core/Economy.gd`

```gdscript
static func wave_bonus(wave: int, cfg: Dictionary) -> int
static func roll_offers(pool: Array, count: int, rng) -> Array
static func reroll_cost(times: int) -> int
```

### `core/Inventory.gd`

```gdscript
static func can_accept(weapons: Array, key: String, max_slot: int, max_lv: int) -> bool
static func merge_or_add(weapons: Array, def: Dictionary) -> Array   # 返回新数组
```

> 全部是 `static`，全部无副作用 → 全部能被 headless 测试覆盖。

## 5. 已知技术坑（写在这里防止重复踩）

| 坑 | 表现 | 解法 |
|---|---|---|
| Godot `--script` 下 `class_name` 不注册 | `Identifier "X" not declared` | 改 `const X := preload("res://core/X.gd")` |
| GDScript 数组元素是 Variant | `Cannot infer the type` | 显式 `int()` / `float()` |
| 测试里 `_ready()` 不自动调用 | 断言失败（数据为空） | 测试里显式调用 `m._ready()` |
| 导出时目标目录不存在 | `Target folder does not exist` | 先 `mkdir -p` |
| Godot Web 需要 COOP/COEP | 网页白屏 | 服务器设响应头，或导出无线程版本 |
| 沙箱 GitHub DNS 被劫持 | 直连 curl 000 | **不要用 gh-proxy 等公共镜像**（会返回假身份！）；用阿里 DoH 查真实 IP 写进 `/etc/hosts` 直连，见 `docs/03` |
| iOS Safari 触摸与安卓不同 | 安卓正常、iPhone 异常 | 必须两台真机都测 |
| 变向延迟高（83ms） | 转向要先把手指收回中心 | 浮点摇杆：手指推出半径后原点跟随（`Movement.follow_origin`），实测降到 33ms |
| 手感"好不好"没法评审 | 只能靠主观描述争论 | 做成纯函数进 `core/`，用 `frames_to_percent()` 断言毫秒数 |
| 导出预设 `threads/enabled=false` | 对 Web 平台无效，wasm 不变 | 换模板本体：`cp web_nothreads_release.zip web_release.zip` |
| Godot Web 要 COOP/COEP | 不加就白屏，加了会拦掉广告/统计脚本 | 用单线程模板导出，实测不加头也能跑（截图 md5 一致） |
| 沙箱无头 Chromium 无 WebGL2 | 截图停在"检查 WebGL2" | 不是游戏问题，手机真机正常，画面只能真机验 |
| 信号声明带参但处理函数写 0 参 | 每次买武器玩家武器不刷新（静默失效） | 处理函数签名要对上信号参数，或声明时就不带参 |
| 函数参数名与成员变量同名 | 函数体内操作的是参数而非成员，成员缓存永远空 → 0 开火 | 参数改名避开成员名（如 `_rebuild_weapons(_ignored)`） |
| ImageGen `background:transparent` 不生效 | 生成图带蓝/白底 + 水印 | 生图时给纯色底，再用边缘泛洪去背 + 最大连通域去水印（`scripts/bgremove.py`） |
| Godot 默认字体（Open Sans）无中文 | 网页导出中文变豆腐块 | 嵌 Noto Sans SC 子集（`fonts/NotoSansSC-Subset.otf`，144KB）作 `gui/theme/default_font` |
| 自动瞄准不打提前量 | 命中率只有 ~25-39%，子弹飞行时间撞上移动敌人就 miss | 敌人数据带 `vel`，开火按 `距离/子弹速度` 预判落点 |
