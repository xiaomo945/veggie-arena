## ✅ 1. 武器合成规则（已按你拍板落地，2026-10-03）
- **合成 = 两把相同 → 升一级**（2 合 1），商店购买**不再自动合成**，落独立槽位；补给站新增「合成」按钮手动把场上相同的两把合上去（Brotato 式格子合成）。
- **价格阶梯**：每级至少 ×2，且硬性保底 **1 级≥20 / 2 级≥40 / 3 级≥80**，高级绝不便宜。
- **刷出档位跟着你已持有的等级走**：没持有只刷 1 级；持有 L 级就刷 [L-1, L]，买已持有的升一级即可再合成（早期波次不会冒出超过进度的货）。
- **售出**：补给站「我的武器」每格带「售 N」按钮，回收价 = 买入价 ×80%，**永不高于买入价**。
- 这些都已上线、单测覆盖、网页试玩可验。请真机/试玩确认手感（尤其「合成」按钮位置和「我的武器」条布局）。
