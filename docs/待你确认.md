# 待你确认 / 需要你拍板的事项

> 以下都不是 bug，是「需要真人手感/审美拍板」的点。AI 不敢替你定，先记着。

## 1. 武器合成规则：现在是 2 合 1，你描述的是 3 合 1
当前逻辑：在商店**再买一把同 key 武器就自动升一级**（2→1），直接买高级武器也行。
你的原话是「每升一级需要三个相同的上一级武器才能升到下一级」（Brotato 式的 3 合 1）。
- 如果你要严格的 3 合 1，我需要改背包模型（每把武器记一个 `count`，满 3 才升级），并同步存档格式。
- 现在商店已能**直接刷出 2~5 级成品武器**（价格逐级 ×3），所以「合不了」的问题已经解决；3 合 1 只是手感细节。

## 2. 终局 Boss / 精英怪的视觉效果
Boss 是多阶段 + 专属 BGM + 演出，精英怪有词缀（护盾/疾风/分裂/易爆）。
这些**无头环境无法渲染**，必须你真机（或网页试玩）看一眼确认演出到位、不穿帮。

## 3. 无尽模式难度曲线
21 波之后血量/伤害/金币/刷怪按 `data/balance.json` 的 `endless` 段封顶增长。
数值是 agent 用模拟配的，但**真人手感**（会不会太肝/太无聊）需要你打几把定。

## 4. Boss 伤害倍率偏保守
agent 给终局 Boss 的 `dmg_mult = 1.25` 并标注「偏保守」。如果你打 Boss 觉得太软/太硬，告诉我调。

## 5. 地图边框配色
现在用「灶台不锈钢包边 + 砧板地砖 + 远景厨房」统一了之前黑底+灰边的割裂感。
钢边/地砖的色调如果你觉得不对，可以再调（颜色集中在 `art/FloorRim.gd` / `art/ArenaFloor.gd`）。
